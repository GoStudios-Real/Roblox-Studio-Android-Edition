FAQ

Do I need to verify my Roblox account?

No. There is no sign-in at all — publishing is authenticated with an Open Cloud API key (create one at create.roblox.com → Settings → API Keys with the universe-places → Write permission). No government ID, no OAuth app, no client secret.

Do I need my computer on for players to play?

No. Publishing uploads your place to Roblox; the game then runs on Roblox's servers. Your phone or PC is only needed while you're editing. This also means your home IP address is never exposed.

What do I need to publish?

Three things: an Open Cloud API key, your game's link (the app auto-finds the Universe ID from it), and a place that already exists on your Roblox account. Everything is saved in Settings → Credentials on your device.

Is it free? Does it work offline?

Yes and yes. The editor, templates and offline AI engine all work without payment or network; only AI model calls (optional) and publishing need a connection. The web app caches its shell for offline use.
